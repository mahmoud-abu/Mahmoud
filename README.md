# Mahmoud — Link in Bio

صفحة هبوط شخصية (Link in Bio) بتصميم زجاجي عصري وخلفية بنفسجية متدرّجة،
تجمع روابط حسابات العمل الحر في مكان واحد. ملف واحد بدون مكتبات خارجية.

A modern single-page **Link in Bio** card (Glassmorphism + animated violet
gradient). No frameworks, no build step.

## 📁 الملفات / Files
```
.
├── index.html          # الصفحة كاملة (HTML + CSS + JS)
├── assets/
│   └── portrait.jpg    # الصورة الشخصية
├── README.md
└── .gitignore
```

## 🚀 طريقة النشر على GitHub لمشاركته كموقع حي

### 1) إنشاء المستودع
- ادخل على https://github.com → اضغط **New** لإنشاء مستودع جديد.
- سمّيه مثلاً `link-in-bio` واختر **Public**، ثم **Create repository**.

### 2) رفع الملفات
- داخل المستودع اضغط **Add file → Upload files**.
- اسحب كل الملفات: `index.html` و`README.md` و`.gitignore` ومجلد `assets`.
  > مهم: ارفع *محتويات* المشروع، بحيث يكون `index.html` في جذر المستودع مباشرة.
- اضغط **Commit changes**.

### 3) تفعيل الموقع (GitHub Pages)
- روح لـ **Settings → Pages**.
- تحت **Source** اختر الفرع `main` والمجلد `/ (root)` ثم **Save**.
- انتظر دقيقة، وبيظهرلك رابط الموقع بالأعلى:
  `https://USERNAME.github.io/REPO-NAME/`
- هذا الرابط بتقدر تشاركه مع أصحابك 🎉

## 🔄 تحديث الصورة لاحقاً
استبدل `assets/portrait.jpg` بصورة جديدة بنفس الاسم وارفعها — بيتحدّث الموقع تلقائياً.
